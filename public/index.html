Este es el despliegue de una aplicación de calculadora de notas finales ponderadas.
Permite calcular una nota final a partir de componentes con peso, usando un arreglo de objetos.
Devuelve la nota con dos decimales y también el percentil p de una lista de números.
El método de percentil es el de rango más cercano, sin interpolación.
Ideal para visualizar y analizar el rendimiento académico de manera sencilla.
